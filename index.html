GSeek

Find your files by what you remember, from GNOME Activities.

Install GSeek · About GSeek

Open the downloaded file in GNOME Software or KDE Discover, or install from a terminal:

flatpak install --user https://flatpak.fariszr.com/gseek.flatpakref

To add the repository:

flatpak remote-add --user --if-not-exists fariszr https://flatpak.fariszr.com/fariszr.flatpakrepo
flatpak install --user fariszr com.fariszr.gseek

Signed packages for x86-64 and ARM64. Updates arrive through your software manager or flatpak update.
